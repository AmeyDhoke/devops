# DevOps Learning Repository

This repository contains my hands-on learning and practice work while exploring **DevOps fundamentals**, with a primary focus on **Version Control** and **CI/CD**.

The purpose of this repository is to understand how modern software development workflows are managed, automated, and maintained using DevOps practices.

## 📌 About

I created this repository while learning the fundamentals of DevOps and experimenting with different concepts related to:

- Version Control
- Git and GitHub
- Repository management
- Commits and commit history
- Branching and merging
- Collaboration workflows
- Continuous Integration (CI)
- Continuous Delivery/Deployment (CD)
- Automation of development workflows

This repository serves as a record of my learning journey and hands-on practice with these concepts.

## 🛠️ Topics Covered

### 1. Version Control

Understanding how version control systems help developers track and manage changes to source code.

Some of the concepts explored include:

- Git fundamentals
- Creating and managing repositories
- Tracking changes
- `git add`, `git commit`, and `git push`
- Viewing commit history
- Working with branches
- Merging changes
- Working with remote repositories
- GitHub-based workflows

### 2. CI/CD

Learning the fundamentals of **Continuous Integration and Continuous Delivery/Deployment** and how automation can be incorporated into the software development lifecycle.

Key concepts include:

- Continuous Integration
- Continuous Delivery
- Continuous Deployment
- Automated workflows
- Build and test automation
- Deployment pipelines
- Triggering workflows based on repository changes
